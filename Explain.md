# Assignment 5.2: Selectors Used

    SELECTOR	           EXAMPLE                    USE
1. Element 	     p { color: red; }	          Selects all paragraph elements.
2. ID            #header { color: blue; }	  Selects an element with a specific ID.
3. Class 	     .box { color: green; }	      Selects elements with a specific class.
4. Universal     * { margin: 0; }	          Selects all HTML elements.
5. Group  	     h1, p { color: black; }	  Selects multiple elements together.
